# Akashconnect

Personal portfolio for Akash Thattanparambil Raju — www.akashconnect.com

Built on the [ThemeWagon Grunge](https://themewagon.github.io/grunge/) Astro + Tailwind template (visual theme retained; content replaced).

## Pages

Home, About, Journey, Experience, Skills, Learning, Recognition, Direction, Contact

## Develop

```bash
npm i
npm run dev
npm run build
```

## Deploy

Static output in `dist/` is published to GitHub Pages (`main` branch root) with CNAME `www.akashconnect.com`.
